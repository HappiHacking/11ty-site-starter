# 11ty Site Starter (Archived)

This repository was retired on 24 September 2026. It is no longer maintained and should not be used as the basis for a new site.

The retirement decision was recorded under Aurora task `046e-00`. The repository had no forks, stars, generated repositories, organization code references, current deployments, or recent human maintenance. Its GitHub Pages site had not been rebuilt since September 2024.

At commit `fdeca29324d282ed680f08e15752c7a0a3158ab9`, a clean `npm audit` reported 13 vulnerable dependency paths: 3 critical, 9 high, and 1 moderate. Archiving the unused template removes the maintenance surface without turning a security cleanup into an unsupported modernization project.

Existing applications must manage their own dependencies. They should not copy versions from this archived starter.
